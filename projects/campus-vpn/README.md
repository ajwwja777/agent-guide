Clash 保留了关联的外层失败证据：`2026-10-01 10:54:05.574`，连接 `remote.hkust-gz.edu.cn:443`，匹配网关域名规则、经公网代理组，报 `context deadline exceeded`。恢复后连接日志显示该组使用“美国2”节点。证据能确认当时网关的代理访问出现超时，不能单独区分家庭网络切换、节点问题或节点到学校网关的链路；不认定学校明确拒绝账号。

当前家里 Wi-Fi 下，对网关 HTTPS 做三轮 DIRECT/现有公网代理 URL 对照：

| 轮次 | DIRECT | 公网代理 |
|---|---|---|
| 1 | 5 秒超时/HTTP 504 | 成功，371 ms |
| 2 | 5 秒超时/HTTP 504 | 成功，370 ms |
| 3 | 5 秒超时/HTTP 504 | 成功，378 ms |

业务复验：Cobot 网页 HTTP 200（约 2.64 秒），A6000 普通 SSH 返回 `a6000-ssh-ok`。因此当前仍需要保留代理网关路径，直接改回 DIRECT 不会依据这些测试提高可用性。三轮成功不等于长期稳定性保证。

公网代理给校园 VPN 增加一层依赖：节点连接失败、网络切换或更换公网节点，可能中断外层 TCP 连接并要求校园 VPN 重连。现有网关规则复用订阅 MATCH 的代理组，改变该组选中的公网节点也会改变后续 VPN 网关连接路径。以后可按需要将 VPN 网关独立选择固定/备用节点，减少与日常浏览换节点耦合；本次只诊断，未增加节点自动切换，也未改变当前可用配置。
