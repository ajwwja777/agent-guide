# 项目启动与维护

从用户指定的机器和目录开始，按当前任务选择新建、clone 或 fork；执行方式以当前对话要求为准。

1. **明确项目与工作位置**：检查已有目录和文档，记录目标、实际位置与下一步；目录约定见[框架总览](../../README.md)。
2. **自动建立 Git 与 GitHub 关系**：按 [GIT.md](GIT.md)执行。新项目默认使用 `ajwwja777` 的公开仓库，由 agent 命名并完成目录、Git 初始化、建仓和 origin 关联；只有需要用户登录或授权操作时才提示。
3. **核验并登记**：核对仓库根、远端与权限，将实际路径、链接和完成状态写入项目记录及指南索引。
4. **按任务发布和继续工作**：提交与 push 按当前要求执行，随后进入所需的数采、训练或部署流程。
5. **同步并汇报**：更新源项目与指南摘要；报告修改文件、已完成步骤和待办。

本文件维护顺序与导航；Git 细节和默认设置统一在 GIT.md。新主题按需新增 MD 并在此链接，项目特例写在项目记录中。
